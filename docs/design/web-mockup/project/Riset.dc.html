Apa yang dibutuhkan web financial tracker?

Pola yang paling konsisten di pesaing: web dipakai sebagai meja kerja untuk meninjau, memahami, dan merencanakan, sedangkan ponsel dipakai untuk mencatat. Rizqflow punya dua modal yang jarang dimiliki pesaing, yaitu metafora rezeki yang mengalir dan modul zakat. Keduanya paling pas ditampilkan di layar lebar.

1. Web adalah meja kerja

Edit massal, antrean tinjau, dan analisa visual lebih sering ada, atau lebih lengkap, di web. Ponsel tetap untuk catat kilat. Ini sejalan dengan keputusan Tahap 14.

2. Rezeki mengalir, bukan sekadar daftar

Diagram aliran (Sankey) adalah fitur khas web pesaing. Bagi Rizqflow ia wujud langsung dari metafora produk. Masalahnya, di web yang sudah live, pemasukan belum dialirkan ke ruang sama sekali.

3. Percaya dulu, baru fitur

Enkripsi ujung ke ujung berarti web butuh langkah buka kunci, tidak ada "lupa sandi", dan pengguna perlu melihat terang siapa melihat apa. Ekspor data dan status sinkron menjaga rasa aman.

1 Peninjauan dan edit massal condong ke web.

Di Simplifi, edit massal ada di web tetapi belum di aplikasi seluler; pengguna menunda koreksi sampai bertemu komputer. Lunch Money menyediakan pilih rentang dengan Shift dan edit massal per kolom.

Lunch Money menandai transaksi impor sebagai belum ditinjau, menampilkan pengingat berisi daftar tersaring, dan menyediakan tombol tandai ditinjau massal. Transaksi yang dibuat manual langsung dianggap ditinjau.

3 Diagram aliran dan laporan tersimpan.

Pusat bantuan Monarch menyebut diagram Sankey hanya tersedia di web. Mereka juga menulis bahwa Sankey akun bersama adalah laporan tersimpan yang populer (klaim vendor), dan punya fitur Year in review.

4 Web sebagai perluasan, dengan dashboard berlapis.

Copilot Money meluncurkan versi web akhir Desember 2025 sebagai perluasan dari aplikasi Apple. Monarch menawarkan dashboard yang bisa disesuaikan (kekayaan bersih, anggaran, tagihan mendatang). Panduan UX dashboard umum menganjurkan ringkasan dulu, rincian menyusul, dan konteks tren. Panduan itu bukan khusus keuangan pribadi.

6 Sistem nol-pengetahuan tidak punya "lupa sandi".

Pada penyimpan sandi zero-knowledge, penyedia tidak bisa mereset sandi master. Solusi umumnya kode pemulihan yang ditampilkan sekali dan disimpan luring. Rizqflow sudah memilih kode 24 kata.

7 Zakat lewat lembaga resmi dapat menjadi pengurang pajak.

UU 23/2011 Pasal 22: zakat yang dibayar ke BAZNAS atau LAZ dikurangkan dari penghasilan kena pajak. Bukti setor memuat nama, NPWP, nominal, tanggal, dan lembaga, lalu dilampirkan ke SPT. Sumber berbeda soal dasar pengurangnya (bruto atau penghasilan kena pajak), dan belum jelas bagi saya apakah zakat mal ikut.

8 Peringatan keras membuat orang berhenti.

Praktisi menyebut "lingkaran rasa malu": bilah merah dan peringatan boros membuat pengguna berhenti membuka aplikasi. Buktinya anekdot, bukan studi terukur. Arahnya sejalan dengan prinsip Rizqflow, tenang bukan panik.

Indie Hackers
 Lemah Kuning plus ikon plus teks, tanpa merah. Bahasa positif ("aman ≈ Rp 175.500 per hari") menggantikan "melewati batas".
9 Pintasan keyboard dan catat cepat di web.

Toshl menyediakan pintasan satu huruf di web untuk pengeluaran, pemasukan, dan transfer. Dalam penelusuran ini saya tidak menemukan aplikasi keuangan pribadi berbasis web dengan command palette sungguhan. Tidak ditemukan belum berarti tidak ada.

Toshl: pintasan web
 Sedang Bilah "Cari atau catat cepat" (Ctrl K), tombol C dan R, serta J, K, X di tabel. Input bahasa natural butuh port parser dari Android.
10 Pengguna spreadsheet pindah bila impor dan ekspor mudah.

Tidak ada sumber langsung tentang alasan pengguna Indonesia bertahan di Excel atau Google Sheets. Ini inferensi dari kebiasaan umum dan dari asal data pemilik (Transaksi Harian). Pelajaran Mint soal portabilitas data ada di riset lama.

 Lemah Impor dan ekspor CSV kelas satu, tabel padat yang terasa seperti spreadsheet.

Yang tidak bisa saya pastikan

  • Pemakaian desktop pengguna Indonesia. DataReportal 2026 tidak memuat pembagian perangkat. Ringkasan pencarian StatCounter menunjukkan desktop 56 sampai 62 persen lalu lintas web pada Juni sampai September 2026, tetapi itu pangsa lalu lintas, bukan pengguna, dan berubah antar bulan. Tidak dipakai sebagai dasar keputusan.
  • Statistik "gagal sinkron keluhan terbesar (34 persen)". Berasal dari agregator komersial dan tidak saya verifikasi. Rizqflow tanpa sinkron bank, jadi risiko setaranya adalah data basi karena lupa mencatat.
  • Klaim fitur pesaing. Banyak sumber adalah situs vendor, afiliasi, atau konten sponsor. Fiturnya belum saya cek langsung di produknya.
  • Riset pengguna Rizqflow sendiri. Belum ada. Tahap 0 (validasi minat) masih berjalan.

Sengaja belum diusulkan

  • Sinkron bank atau e-wallet otomatis: riset lama menyimpulkan rapuh dan terhambat lisensi di Indonesia.
  • Bot WhatsApp, input AI, dan insight otomatis: sudah diputuskan menyusul setelah rilis.
  • Multi-mata uang dan widget dashboard yang bisa disusun ulang: nilainya belum terbukti untuk pasar Anda.

Hubungan dengan riset lama

Riset di docs/research-market/research.md (23 September 2026) tetap berlaku untuk aplikasi secara umum: input cepat, multi-dompet, keluarga berbasis peran, pos lokal seperti zakat dan arisan, dan tanpa auto-sync bank di tahap awal. Papan ini hanya menambahkan lapisan khusus web.
